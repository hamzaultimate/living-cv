Case study

Telemetry Pipeline — real-time ingestion at scale

Lead backend engineer · Contoso Cloud · 2023–2024

An event-driven pipeline ingesting millions of device events per hour with sub-second dashboards.

▸ Sustains ~20k events/second at peak with zero dropped events

▸ Dashboard latency dropped from minutes to under 1 second

▸ Cut infrastructure cost ~35% versus the previous design

Problem

Device telemetry was arriving faster than the legacy monolith could store it, causing dropped events and dashboards that lagged minutes behind reality.

Approach

Rebuilt ingestion as a set of stateless .NET microservices behind a message broker, with batched writes, back-pressure, and a read model tuned for the dashboard's exact query shape.

Stack

.NET Core C# Azure Service Bus MS SQL Server Redis
